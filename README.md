# webParser — парсер каталога с выгрузкой в Excel, CSV и Google Таблицы

[![CI](https://github.com/TaRosh/webParser/actions/workflows/ci.yml/badge.svg)](https://github.com/TaRosh/webParser/actions/workflows/ci.yml)

Собирает каталог товаров (на примере учебного магазина
[books.toscrape.com](https://books.toscrape.com) — 1000 книг) и сохраняет
результат в удобную таблицу. Работает **вежливо**: соблюдает правила сайта,
не перегружает его и останавливается, если сайт просит об этом.

## Что получается на выходе

| Название | Цена | Валюта | Рейтинг | В наличии | Количество | Категория | UPC | Ссылка |
|---|---|---|---|---|---|---|---|---|
| A Light in the Attic | 51.77 | GBP | 3 | да | 22 | Poetry | a897fe39b1053632 | https://books.toscrape.com/catalogue/a-light-in-the-attic_1000/index.html |
| Tipping the Velvet | 53.74 | GBP | 1 | да | 20 | Historical Fiction | 90fa61229261140a | https://books.toscrape.com/catalogue/tipping-the-velvet_999/index.html |
| Soumission | 50.10 | GBP | 1 | да | 20 | Fiction | 6957f44c3847a760 | https://books.toscrape.com/catalogue/soumission_998/index.html |

- **Excel (.xlsx)** — цена числом (можно считать и сортировать), закреплённая
  шапка, фильтры, кликабельные ссылки.
- **CSV** — для импорта в другие программы (UTF-8 с BOM, разделитель — запятая).
- **Google Таблица** — лист перезаписывается при каждом запуске
  ([настройка за 10 минут](docs/GOOGLE_SHEETS.md)).

Два режима:

| Режим | Поля | Запросов | Время* |
|---|---|---|---|
| быстрый (по умолчанию) | название, цена, рейтинг, наличие, ссылка | 50 | 1–4 мин |
| подробный `-details` | + количество, категория, UPC | 1050 | ~20 мин |

\* при паузе 1 с между запросами; зависит от скорости сайта.

## Вежливость и законность

Правила зашиты в код — отключить их флагом нельзя:

- **robots.txt** проверяется перед каждой страницей (стандарт RFC 9309);
  закрытые страницы не скачиваются. Если robots.txt недоступен — сайт считается закрытым.
- **Пауза между запросами** — не меньше 1 секунды или больше, если сайт
  просит (`Crawl-delay`). Действует и при параллельной обработке.
- **Повторы при сбоях** с растущей паузой (1 с, 2 с, 4 с…) и учётом `Retry-After`.
- **Ответ 403 или повторный 429 — остановка**, без смены IP и обхода защиты.
- **Честный User-Agent** со ссылкой на этот репозиторий.
- Собираются только факты (цены, наличие). Тексты описаний и фото — нет:
  это авторский контент.

Перед каждым заказом на парсинг проходится [чек-лист](docs/PRE_ORDER_CHECKLIST.md):
персональные данные, правила сайта, официальный API.

## Запуск

### Docker (ничего, кроме Docker, не нужно)

```bash
docker compose run --rm parser                          # все книги → out/books.xlsx
docker compose run --rm parser -limit 100 -out out/books.csv
docker compose run --rm parser -details                 # с категориями и UPC
```

Результат появится в папке `out/`. На Linux добавьте `--user "$(id -u):$(id -g)"`,
чтобы файлы принадлежали вам, а не root.

### Готовый бинарник

```bash
task build                     # bin/webparser (Linux) и bin/webparser.exe (Windows)
./bin/webparser -limit 100
```

### Флаги

| Флаг | По умолчанию | Описание |
|---|---|---|
| `-url` | первая страница каталога | откуда начинать |
| `-details` | выкл. | скачать страницу каждой книги |
| `-limit` | 0 (все) | сколько книг собрать |
| `-out` | `out/books.xlsx` | файл `.xlsx` или `.csv`; пусто — не сохранять |
| `-sheet` | — | ссылка на Google Таблицу |
| `-sheet-name` | `Книги` | лист в таблице |
| `-credentials` | `credentials.json` | ключ сервисного аккаунта Google |
| `-delay` | `1s` | пауза между запросами (меньше 1 с нельзя) |
| `-workers` | 4 | параллельная обработка книг в режиме `-details` |
| `-v` | выкл. | подробный лог |

**Ctrl+C** — остановить и сохранить уже собранное; повторный Ctrl+C — выйти сразу.
Если сайт ограничил доступ посреди работы, собранное тоже сохраняется.

## Как адаптировать под другой сайт

1. Пройти [чек-лист](docs/PRE_ORDER_CHECKLIST.md).
2. Сохранить 2–3 страницы сайта в `internal/catalog/testdata/`.
3. Поменять CSS-селекторы в `internal/catalog/catalog.go` и тесты под новые страницы.
4. Поменять колонки в `internal/export/export.go`.

Остальное — вежливый клиент, обход, выгрузка — работает без изменений.
Если сайт сменит вёрстку, парсер сообщит об этом понятной ошибкой
(«не найдены ожидаемые элементы»), а не выгрузит пустую таблицу.

## Устройство

```
cmd/webparser/      CLI: флаги, прогресс, сохранение результата
internal/
  robots/           разбор robots.txt по RFC 9309
  fetch/            вежливый HTTP-клиент: robots, лимит частоты, повторы, остановка
  catalog/          разбор HTML (goquery): каталог, страница книги, цены
  crawl/            обход: очередь страниц, пул воркеров для книг
  export/           CSV, Excel, Google Таблицы
docs/               чек-лист перед заказом, настройка Google Таблиц
```

## Качество

```bash
task check     # линтер (golangci-lint) + тесты с детектором гонок
task cover     # покрытие
```

Тесты не ходят в сеть: используют сохранённые страницы сайта, фальшивые
HTTP-серверы и фальшивый Google Sheets API. Проверяются в том числе
блокировки (403/429), повторы, зацикленная пагинация, Ctrl+C посреди работы.
CI (GitHub Actions) запускает тесты, линтер и сборку Docker-образа на каждый push.

Стек: Go 1.27, goquery, excelize, Google Sheets API, golang.org/x/time/rate, Docker (distroless, ~21 МБ).
